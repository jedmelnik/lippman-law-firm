# Law Offices of Eliot M. Lippman

Modern Next.js rebuild of [lippmanlawfirm.com](https://www.lippmanlawfirm.com/) - San Rafael conservatorship, probate, trust administration, and estate planning.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- shadcn/ui primitives

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
